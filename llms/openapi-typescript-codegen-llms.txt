# OpenAPI TypeScript Codegen

> OpenAPI TypeScript Codegen is an MIT-licensed Node.js library and CLI by Ferdi Koomen that reads an OpenAPI 2.0 or 3.0 specification (JSON or YAML, from a path, URL, or string) and generates a lightweight, fully typed TypeScript client. It emits models, services, and core runtime files for one of five HTTP clients — fetch, node-fetch, XHR, Axios, or Angular — and supports cancelable promises, union types instead of enums, runtime schemas, and external `$ref` resolution. The maintainer has publicly declared the project unmaintained and asks users to migrate to `@hey-api/openapi-ts`, a fork that continues the work; despite that, maintenance releases shipped in December 2025 (0.30.0) and June 2026 (0.31.0), and the package still records roughly 2.46 million npm downloads a month. There is no hosted API, no developer portal, and no service to sign up for — this is a build-time tool distributed on npm.

## Install

- [npm — openapi-typescript-codegen](https://www.npmjs.com/package/openapi-typescript-codegen): `npm install openapi-typescript-codegen --save-dev`. Installs the `openapi` binary.

## CLI

- [Usage](https://github.com/ferdikoomen/openapi-typescript-codegen#usage): `openapi --input ./spec.json --output ./generated`. Required flags are `-i/--input` and `-o/--output`; `-c/--client` selects `fetch` (default), `xhr`, `node`, `axios`, or `angular`.
- [Command surface (artifact)](cli/openapi-typescript-codegen-cli.yml): every documented flag, default, and example, captured from the README.

## Status and migration

- The maintainer's [announcement](https://github.com/ferdikoomen/openapi-typescript-codegen#important-announcement) asks users to migrate to [@hey-api/openapi-ts](https://github.com/hey-api/openapi-ts).
- [Migration guide](https://heyapi.dev/openapi-ts/migrating.html#openapi-typescript-codegen): moving from `openapi-typescript-codegen` to `@hey-api/openapi-ts`.
- The announced follow-through was not executed: the repository is not archived (210 open issues as of 2026-08-05) and no npm version carries a `deprecated` flag as of 2026-08-06.

## Not published

- No hosted API, no `baseURL`, no OpenAPI describing a service of its own.
- No developer portal, pricing page, sign-up, terms of service, or privacy policy — the tool is free and MIT-licensed.
